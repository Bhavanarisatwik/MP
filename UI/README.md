# UI Angular Project

This folder contains an Angular app scaffolded with Angular CLI.

Location: `ui-app`

Quick start (PowerShell):

1. Change directory into the app

   cd .\UI\ui-app

2. Install dependencies (if not already installed)

   npm install

3. Serve the app

   npm start

The app will be available at http://localhost:4200 by default.

Notes:
- The app was created with Angular CLI 16.x using SCSS and routing enabled.
- If you want the project at the root of `UI` instead of `UI/ui-app`, tell me and I can move files.
